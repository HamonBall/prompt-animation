## Delivered

`src/avatar_app/planning/retrieval.py` exposes a catalog index. Use `retrieve` with a
calibrated profile, measured entry and resolved surfaces for planner input.
`search` and `family_alternatives` return unchecked discovery metadata.
The checked path resolves supplied per-movement parameters, validates the instance
and builds its pure fragment to exercise side, measurement, support and entry checks.
A matching rig/profile/version review and validated parameter envelope are required
for reviewed status. The caller supplies trusted reviews via the existing catalog API.
A fresh catalog contains no review records, so its usable candidates are experimental.

The initial page holds up to 12 candidates and a separate bounded list of limitations.
A miss preserves the prompt. Choosing a family returns a separate filtered alternatives page that preserves the miss.
The edit context carries the selected instance, original clauses, explicit parameter
names, root movement parameters, schedule, relations, contacts, goals, styles and loop.
The serializer rejects an oversized payload. Stage 10 must budget its own final
messages and schema and decide whether all clauses can be fulfilled.

## Parameters, frames and supported review envelope

Authoritative generated parameter schemas: `tests/fixtures/head_neck/v1/<rig>/parameters.json`;
definitions: `src/avatar_app/movement_library/joints.py`. Full meanings/defaults and
API migration: `docs/contracts/head-neck-v1.md`.

Shared parameters are duration_s **0.8..3 seconds per stroke**, default 1; hold_s
**0..1 second**, default 0.2; return_policy preserve_end/return_to_entry. Default is
preserve_end for look and return_to_entry otherwise. Timing rounds up to execution
frame boundaries. World return retains at least one measured arrival frame and binds
its return from the achieved orientation. Entry values, explicit zero and contacts are
preserved; no neutral reset or out-of-range clamping occurs.

Review applies to the procedural demo and differently proportioned Hip Hop Mixamo rigs,
with neutral and bent/90-degree-turned entries. The bent fixture also carries torso
pitch 15, head pitch 10, head yaw -20 and an already bent left arm. All authored scalar
targets must fit the actual profile. Root, pelvis, limb targets and contact obligations
are unchanged; actual preservation residuals remain within the shared limits below.

The **registry head.look review envelope is torso mode**. World mode is reviewed for
the explicit tested point fixtures: 3 m away, left/right 25-degree directions, with a
30-degree externally authored torso turn while holding the point. Broader software
input bounds (0.25..10 m head-to-point distance, within the 20 m world-coordinate budget
and current angular envelope) are validated, but arbitrary world points/parent paths
are not advertised as reviewed. A coincident, near-vertical or unreachable target fails.
General composed parent trajectories remain for the assigned composition stages.

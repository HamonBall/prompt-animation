## finger.curl_spread — reviewed for the declared Mixamo envelope

Default: all digits, curl .25 normalized, spread 0, left, shared timing/return
defaults above. Selection supports all, four_fingers and each named digit.
Curl 0–1 scales each selected joint to 0–90 degrees, thumb 0–65. Base spread
-20–20 degrees, with thumb effective bound -15–15. Nullable per-digit overrides
must name selected digits. Positive spread points thumbward in the calibrated
parent frame; a common group angle means the same signed angle for each digit.
Individual signed overrides can express a fan; automatic fan/opposition is not
claimed. Unselected digits, wrist, palm and arm trajectories remain independent.

**Passed:** fifteen positive native cases /1,434 samples: defaults, zero/maximum
curl, signed group-spread bounds, thumb bounds, every digit selection, per-digit
asymmetry, minimum/maximum timing and preserve_end, both sides and yawed/bent
entries. Maximum tracking residual .000207445 degrees, native world-joint speed
269.956493 degrees/s, acceleration 688.139227 degrees/s². Full views show smooth
curl/spread transitions and recovery, readable individual selection and stable
unrelated hands/body. No obvious crossing or abrupt deformation was observed
from the reviewed angles. No contact/collision solver is claimed.

Invalid types, nonfinite values, ranges, enum/unknown/inactive overrides and
missing selected anatomy reject in contract checks. A partial profile can request
supported digits; missing anatomy is never synthesized.

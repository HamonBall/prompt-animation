## Implementation and validation plan

Profile 8 extends the calibrated leg profile with rigid heel and forefoot
contact points derived from low weighted foot geometry. These points follow
the ankle and require no toe bone. Profiles 1–7 retain their existing
measurements and floor-contact path. The new fragment builder uses the
existing sampling, baking and leg IK path. Supported pivot phases solve the
ankle endpoint from the captured world contact and sampled orientation. The
opposite sole remains planted. Free ankle and toe tracks measure and apply
parent-relative motion. Fine toe curl requires the selected mapped toe.

The targeted checks exercise new contracts and the previous leg contracts.
Numeric runs use isolated Blender 5.1 workers with two threads. Run demanding
cases first, then the required current-source matrix and affected floor/seat
and leg regressions. Only then generate front and side lossless saved-motion
evidence through the shared managed runner. Review the complete trajectories
and run storage accounting. These are separate gates.

The full artifact baseline is 2,736,707,315 bytes across 63,332 files,
60,421,083,136 free bytes, zero temporary bytes and no writer leases. The
baseline inventory is `artifacts/stages/05.5/storage-before.json`. Initial
preflight reserved 8 MiB retained and 32 MiB temporary for the first checks.
The stage and global hard limits are 512 MiB and 4 GiB. Shared assets and
runner maintenance count globally. All accepted 05.4 evidence is preserved.

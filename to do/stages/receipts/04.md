## Delivered interfaces and files

- `src/avatar_app/movement_library/compiler.py`: pure instantiate_movement(),
  build_fragment(), prepare_fragment(), sample_motion(), and a per-run ExecutionCursor.
  Hold/transition curves support scalar/vector interpolation and shortest-arc quaternion
  slerp. Runtime measured-entry bindings are captured once from the same pre-application
  snapshot for simultaneous activations. No bpy/model import or scene mutation occurs.
- `src/avatar_app/blender/primitive.py`: calibrated application, independent measurement,
  entry/reach/capability preflight, source diagnostics, unrelated-target preservation
  and measured-goal review. Supported application is head/neck/torso/spine scalar controls,
  world hand endpoints through existing IK, and existing floor sole anchors. Other
  measured quantities fail precisely until their owning stage implements application.
- `src/avatar_app/blender/motion.py`: ExecutableMotion branch inside the existing frame
  loop. Legacy and typed execution share keyframe insertion, progress, review and the
  candidate transaction. Cancellation/failure restores action/slot, pose/rotation modes,
  timeline, FPS/base/subframe and camera. Typed results expose samples, ending_state and
  source_map; the legacy result shape and 12-stage limit remain intact.
- `tools/preview_movement.py`: explicit ID/version, parameter JSON/file, rig, entry fixture
  and output directory; optional rendering. It saves a real keyframed preview.blend,
  input records, measured result.json, all rendered frames and contact sheets. It makes
  no model call and adds no user-facing preset controls.
- `tests/test_primitive_execution.py`, `tests/blender_primitive_execution.py` and

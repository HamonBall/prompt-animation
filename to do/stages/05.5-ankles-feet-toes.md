## Execution

1. Calibrate heel, forefoot and sole reference locations from the existing foot geometry/profile. Distinguish ankle articulation from inherited hip/leg orientation.
2. Define supported versus free-foot parameter ranges and required anchors. Build foot.place/lift/tap with explicit swing clearance and acquisition/release intervals.
3. Represent heel/toe pivots as attachment to the relevant contact point, not translation of the whole planted foot. Add validated contact-anchor identifiers while preserving legacy whole-foot semantics.
4. Reuse existing leg solving to coordinate the chain and pelvis only when declared. Compile heel-to-sole-to-toe progression as one finite movement.
5. Enable toes.curl only for mapped toe bones; keep heel/sole contact mechanics usable without fine toe articulation.

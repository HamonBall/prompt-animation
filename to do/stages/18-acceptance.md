## Plan

**Permitted changes:** Reproducible acceptance suite, final relevant regression run, current README/capability ledger and acceptance receipt. Focused fixes only for newly exposed integration defects.

## Execution

1. Freeze a documented suite covering isolated joints, compound actions, supported transitions, aerial metaphors, loops, object interaction, corrections and failure handling. Include at least 20 routine supported prompts and 10 held-out novel/paraphrased combinations.
2. Score explicit-clause coverage, actual motion quality and visible intent separately. Include fish-like flight, chest-height wrists/forward elbows, knee lift with palms up, walking+wave+look, puppet style and a wrist-only follow-up.
3. Run on the supplied rig and a different imported rig. Keep baseline/default-avatar behavior, one-result flow, requested loop metadata, progress, cancellation and previous-result restoration.
4. Publish the implemented capability/parameter envelope and measured performance. List omitted optional stages or unsupported anatomy/objects explicitly; do not hide them behind a general arbitrary-motion claim.
5. Update the stage index status using receipts. Close only completed work packages; create a specific follow-up for an unresolved failure rather than declaring the roadmap complete.

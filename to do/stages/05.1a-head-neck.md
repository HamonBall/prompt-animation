## Execution

1. Implement each ID with side/direction where relevant, target angle or target point, duration, hold and return policy. Use one nod/shake cycle initially; stage 05.7a adds generic repetition.
2. Make target frames explicit: torso-relative look moves with the torso; a world-target look maintains its target as the body turns. Respect the profile's angular and reach envelopes.
3. Distribute neck/head motion only when neck.lead is requested and the neck capability exists. On a head-only rig provide an explicitly labeled approximation rather than advertising neck articulation.
4. Register entry conditions, owned head/neck chains and measured-goal checks. Leave root, pelvis, limbs and support goals unchanged.

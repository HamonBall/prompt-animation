## Plan

Support intentional whole-avatar travel and airborne orientation independently of pelvis adjustments and original neutral foot anchors.

**Permitted changes:** Root trajectory records/sampling, root application/measurement adapters, root.travel/turn/orient/hover entries and tests.

## Execution

1. Implement a root trajectory with explicit world/body frame, position/orientation and duration. Keep local pelvis coordination separate. Rebase current foot/contact anchors consistently when continuing after travel.
2. Add root.travel along bounded line/arc paths, root.orient, root.hover and a turn primitive that declares whether it requires planted pivot/steps or free airborne rotation.
3. Represent grounded and stylized airborne modes explicitly. Airborne motion disables automatic settling while retaining floor/body collision checks. Existing takeoff stages retain their temporary-flight semantics.
4. Preserve the requested airborne endpoint instead of forcing an unrequested landing. Add ramped entry/exit only where the recipe requests it; root primitives must state starting-state requirements.
5. Allow humanoid flight without wings/fish anatomy, scenery or a physics claim. Limit root positions to the shared workspace bounds and record achieved trajectory.
